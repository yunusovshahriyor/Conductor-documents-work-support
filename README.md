# Проводник: документы, работа, поддержка

PWA и сайт, который помогает мигрантам из Таджикистана, Узбекистана, Кыргызстана и других стран
с документами, сроками, работой и поддержкой в России.

Языки: тоҷикӣ (`tg`), русский (`ru`), oʻzbekcha (`uz`), кыргызча (`ky`).

## Структура

- `frontend/` — Next.js 15 (App Router) + React 19 + TypeScript. Установка как PWA, работа офлайн.
- `backend/` — появится на следующем этапе.

## Запуск фронтенда

```bash
cd frontend
npm install
npm run dev                    # http://localhost:3000
npm run build && npm start     # production, включает service worker
```

## Что уже есть (этап 1: внешний вид)

- Главная, «Документы» (чек-лист из 5 шагов), «Сроки» (калькулятор), «Работа», «Помощь», «О проекте».
- Мультиязычность без внешних библиотек: `frontend/src/i18n/messages/{ru,tg,uz,ky}.ts`.
  Тип `Messages` берётся из `ru.ts`, поэтому пропущенный ключ в любом языке — ошибка компиляции.
- Выбор языка: cookie → `Accept-Language` → `ru` (`frontend/src/middleware.ts`).
- PWA: `public/manifest.webmanifest`, `public/sw.js`, `public/offline.html`, иконки в `public/icons/`.
- Отметки и даты хранятся только в `localStorage` на устройстве, на сервер ничего не отправляется.

## Что нужно проверить до публикации

- **Правовое содержание.** Сроки в `frontend/src/lib/rules.ts` (7 рабочих дней на учёт, 90 из 180 дней)
  и тексты шагов должен подтвердить юрист; поле `lastVerified` пока `null`.
  Калькулятор считает «90 дней» упрощённо (от даты въезда), без учёта предыдущих поездок в окне 180 дней.
- **Переводы** на tg/uz/ky черновые — их должен вычитать носитель языка.
- **Контакты помощи**: пока указан только 112; списки НКО, юристов и консульств добавить после проверки.
